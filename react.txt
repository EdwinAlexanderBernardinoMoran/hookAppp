- No se recomienda poner un useEffect sin ni una dependencia. (callback, valor de retorno, dependecias)
- Si le mandamos un arreglo vacio entonces solo se ejecutara una vez
- Se recomienda crear efectos especializados, que hagan una sola accion.

- El segundo valor de retorno de useEffect sirve para destruir listener por ejemplo a la hora que el componente se destruye esto se le conoce como unmont o cleanup.
- El componente unicamente se destruye solo si se renderiza por medio de una condicion, es decir por ejemplo si el componente tiene la clase 'hidden' entonces nunca se destruira.

- Si un componente tiene mucha logica  talvez sea necesario separa locia en funciones externas.
- Si es necesario de hacer cambios o redibujos en el state utilizamos Customhooks.
